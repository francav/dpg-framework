# dpg-framework

Concepts and normative specification for **Deterministic Process Governance (DPG)** — an open,
neutral foundation for governing the behavioral predictability of automated BPM processes.

This repository hosts the conceptual documentation and the normative specification prose. It is the
human-readable counterpart to the machine-readable schemas in `dpg-spec`.

## Status

Early development (0.1.0). Content and structure are unstable and subject to change.
